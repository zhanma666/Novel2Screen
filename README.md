# Novel2Screen
基于大语言模型的小说影视化创作平台。支持故事图谱构建、剧本生成、分镜规划、剧本审校与人机协同创作。
## 核心功能
1.小说上传与解析
支持TXT、DOCX格式小说上传，自动进行文本解析与章节拆分。
2.构建人物关系图谱
自动抽取人物、身份及人物关系，并生成可视化人物关系图谱。
3.生成故事图谱
自动提取人物、事件、地点与时间信息，构建故事知识图谱。
4.多风格剧本改编
支持电影、电视剧、短剧、动漫等多种剧本风格生成。
5.AI剧本审校
自动检查角色一致性、时间线合理性、场景完整性和对白分布情况，并提供修改建议。
6.人机协同创作
支持用户在线编辑剧本，系统实时更新审校结果与质量评估信息。
7。分镜脚本生成
根据剧本自动生成镜头设计、景别、运镜方式、光线建议及镜头时长。
8.剧本质量评估
从完整性、一致性、场景连续性等多个维度对剧本进行评分。
9.导出YAML格式剧本
按照统一Schema导出结构化YAML剧本文件。
